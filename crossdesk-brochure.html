원격 화면 공유 · 제어 · 파일 전송

맥과 윈도우를 같은 네트워크에서 곧바로 잇습니다

한쪽에서 여섯 자리 코드를 부르면 다른 쪽이 접속합니다. 화면이 흐르고, 마우스와 키보드가 건너가고, 파일이 오갑니다. 계정도, 중계 서버도, 설정 파일도 없습니다. 두 대 사이에 오직 하나의 TCP 연결만 존재합니다.

호스트

화면을 보여 주는 쪽

주소 · 포트 · 코드를 표시하고 접속을 기다립니다. 제어를 허용할지는 체크박스 하나로 언제든 바꿉니다.

TCP · 포트 47820
중계 서버 · 클라우드 계정 · 로그인
뷰어

화면을 보고 조작하는 쪽

주소와 코드를 넣고 접속합니다. 한 번 연결한 상대는 다음부터 목록에서 한 번의 클릭으로 이어집니다.

연결되면 할 수 있는 일

세 가지가 하나의 연결 위에서 동시에 돌아갑니다. 따로 켜고 끄는 모드가 아닙니다.

상대 화면 보기

호스트의 주 화면을 실시간으로 받아 봅니다. 해상도가 달라도 창 크기에 맞춰 비율 그대로 표시됩니다.

초당 15프레임 · 최대 1080p · JPEG

원격으로 조작하기

마우스 이동·클릭·스크롤과 키보드 입력이 상대 컴퓨터에 그대로 들어갑니다. 단축키와 한글 입력도 함께 넘어갑니다.

양쪽이 모두 켜야 동작 — 한쪽만 꺼도 즉시 차단

파일 주고받기

양방향으로 보냅니다. 받은 파일은 자동으로 다운로드 폴더 아래 CrossDesk 폴더에 쌓이고, 같은 이름이 있으면 번호를 붙입니다.

한 개당 최대 4 GiB

처음 한 번만 코드, 그다음부터는 클릭 한 번

매번 코드를 부르지 않아도 됩니다. 코드로 확인된 기기에는 호스트가 인증 키를 발급하고, 뷰어는 그 키를 보관합니다.

  1. 01

    호스트가 공유를 시작합니다

    주소와 포트, 그리고 그 자리에서 만들어진 여섯 자리 코드가 화면에 뜹니다.

  2. 02

    뷰어가 코드로 접속합니다

    주소·포트·코드를 넣고 연결합니다. 코드 입력에는 8초의 여유가 있습니다.

  3. 03

    호스트가 그 기기에 키를 발급합니다

    기기 이름표가 붙은 256비트 키입니다. 뷰어는 자동으로 보관합니다.

  4. 04

    다음부터는 목록에서 바로 연결됩니다코드 불필요

    호스트는 발급한 키 목록을 언제든 볼 수 있고, 기기 단위로 회수할 수 있습니다. 회수된 기기는 다시 코드를 받아야 합니다.

윈도우의 관리자 권한 화면까지

대부분의 원격 도구가 멈추는 지점이 있습니다. 관리자 권한으로 실행된 창과 UAC 동의 화면은 일반 프로그램의 입력을 받지 않습니다. 앱을 관리자로 실행해도 마찬가지입니다.

기본 상태

일반 창은 모두 조작됩니다. 관리자 권한 창과 UAC 동의 창에서는 제어가 멈추고, 윈도우 앞에 있는 사람이 직접 눌러야 합니다.

도우미를 켠 상태선택

관리자 승인을 한 번 받아 배경 서비스를 등록합니다. 그 뒤로는 UAC 동의 창이 뷰어에 그대로 보이고, 원격에서 누를 수 있습니다.

호스트 화면에서 켜고 끄기 · 재부팅 후에도 유지

알아야 할 것

이 기능을 켜면 원격 제어를 허용한 상대가 사실상 관리자 권한까지 쓸 수 있게 됩니다. 필요한 동안만 켜기를 권합니다.

무엇을 지키고, 무엇을 지키지 않는가

CrossDesk는 신뢰하는 네트워크를 전제로 만들어졌습니다. 감추지 않고 적어 둡니다.

설계상 지키는 것

  • 화면과 파일이 제3자 서버를 지나지 않습니다. 트래픽은 두 컴퓨터 사이에만 머뭅니다.
  • 계정이 없으므로 유출될 자격 증명도 없습니다.
  • 제어는 양쪽이 모두 켜야 시작되고, 호스트가 끄면 그 즉시 멈춥니다.
  • 인증 키는 기기별로 발급되고 개별 회수됩니다.
  • 받은 파일은 정해진 폴더 밖으로 나가지 않고, 기존 파일을 덮어쓰지 않습니다.

지키지 않는 것

  • 통신을 암호화하지 않습니다. 같은 네트워크의 도청자는 화면과 입력을 볼 수 있습니다.
  • 코드 추측 시도에 횟수 제한이 없습니다.
  • 인터넷을 넘는 접속은 지원하지 않습니다. 같은 네트워크에 있어야 합니다.
  • 접속 기록을 남기지 않습니다.

신뢰할 수 없는 망을 거쳐야 한다면 VPN이나 SSH 터널 안에서 쓰십시오.

필요한 것

운영체제 macOS 12.3 이상 (Apple Silicon · Intel) · Windows 10/11 64비트
네트워크 두 컴퓨터가 같은 공유기·같은 대역에 연결. 호스트는 47820 포트로 접속을 받습니다.
macOS 권한 화면을 공유하려면 화면 기록, 원격 조작을 받으려면 손쉬운 사용을 허용합니다. 허용 후 앱을 다시 실행하세요.
Windows 앱 권한은 없습니다. 처음 실행할 때 뜨는 방화벽 허용 창에서 접속을 허용하면 됩니다.
설치 macOS는 디스크 이미지에서 응용 프로그램으로 끌어 넣고, Windows는 설치 프로그램을 실행합니다. 관리자 권한이 필요 없습니다.
